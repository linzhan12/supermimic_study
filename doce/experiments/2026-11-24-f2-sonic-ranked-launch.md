# F2.3 用世界模型排序支撑反解生成的斜步

沿用同一实测支撑和同一 checkpoint。启动时构造两个时长及三个骨盆倾斜幅度的可解候选，约束足姿不变。候选先将末端补齐到预演窗口，再按 [实际指令误差与追踪损失](2026-11-24-f2-sonic-predicted-twist.md) 排序。选中的完整一段由 motion actor 执行。

| 组别 | 左斜走实际前向 / 横向（m/s） | 右斜走实际前向 / 横向（m/s） |
| --- | ---: | ---: |
| 固定 0.48 s，无倾斜 | −0.053 / +0.064 | −0.083 / −0.069 |
| 0.48 s 起评，预演选 0.48 s / 0.12 rad | −0.048 / +0.084 | +0.109 / +0.054 |
| 0.60 s 起评，预演选 0.60 s / 0.12 rad | −0.021 / +0.080 | +0.112 / −0.089 |

0.60 s 起评组在本场景保留了两侧横向符号，右斜走前向转正，左斜走的前向仍偏负。右侧指令没有触发第二次合成步，使用此前已存在的方向参考。预演能对生成姿态作选择，尚不足以把左斜走跟到给定 `[0.25,+0.20] m/s`。这一消融仍未达到 F2。

复现沿用 [从双脚实测支撑合成第一斜步](2026-11-24-f2-sonic-contact-launch.md) 的 0.48 s 或 0.60 s 组，并加 `--rank-contact-launch True`，保存到 `outputs/f2-sonic-launch-rank-{48,60}`。每个候选分数及选择见轨迹的 `planner_candidates`。
