# P0 平地三路回放实验

2026-11-23，代码版本 `7ace498`。

## 问题与预期

同一个 G1 策略读取完整参考、参考速度或固定摇杆命令时，分别能否起步、停步和转向？预期完整参考能提供可用对照，独立摇杆会更容易暴露起步和转向问题。若在同一初态下复现这一差异，就进入独立速度奖励基线的验证。

## 配置与复现

- 三路使用同一个本地 checkpoint `2026-11-17_17-55-41`。该旧 checkpoint 用现有默认网络配置加载，actor 使用 `rep_state`，历史长度为 1。
- 三路分别使用 `walk1_subject1.npz` 的第 0 帧和第 205 帧作为配对初态。仿真在 CPU 上运行，控制频率 50 Hz，种子为 0。两组计划时长为 10.5 s 和 3.0 s。
- A 使用完整参考目标。B 使用同片段的速度，经 25 帧平滑、按参考骨盆航向投影并裁剪到配置范围。C 使用固定的起步、左右转向、斜移和精确零速命令。A、B 的速度误差使用相同参考速度，C 的误差用各阶段实际下发的命令。
- 每行轨迹将时刻 `t` 的 actor 目标和动作与 `t+1` 的骨盆速度、足地接触和腰部角度对应。共用的提前结束判据为骨盆高度低于 0.45 m 或倾斜超过 60°。

```bash
cd /home/hi/SuperMimic-Official/supermimic
P0_OUT=outputs/p0-g1-replay-copy
OMP_NUM_THREADS=2 .venv/bin/python scripts/eval_p0.py \
  --checkpoint-dir logs/SuperMimic-GenCoord-G1/2026-11-17_17-55-41 \
  --motion-file ../data/lafan1_official/walk1_subject1.npz \
  --output-dir "$P0_OUT"
```

首轮原始记录位于被 Git 忽略的 `supermimic/outputs/p0-g1-20261123/`。该目录包含 `summary.json`、六条 JSONL 轨迹、`simulation.log` 和 `git_commit.txt`。脚本会记录权重和动作文件的 SHA-256。

## 现象

六条轨迹均跑满计划时长，未触发上述骨盆终止条件。两次 CPU 运行的轨迹和摘要逐字节相同。检查确认两类初态在各自三路之间一致，每个零速保持段的 actor 命令始终是 `[0, 0, 0]`。

| 初态 | 路线 | 前向 MAE（m/s） | 侧向 MAE（m/s） | 偏航 MAE（rad/s） |
| --- | --- | ---: | ---: | ---: |
| 近静止 | A 完整参考 | 0.074 | 0.059 | 0.101 |
| 近静止 | B 参考速度 | 0.099 | 0.082 | 0.118 |
| 行走中 | A 完整参考 | 0.101 | 0.089 | 0.152 |
| 行走中 | B 参考速度 | 0.140 | 0.155 | 0.174 |

固定摇杆 C 给出 `0.35 m/s` 前进命令时，近静止初态的平均前向速度仅 `0.023 m/s`，对应段双脚触地率为 100%。随后左右转向的目标偏航为 `+0.40` 和 `−0.40 rad/s`，实测均值分别为 `+0.024` 和 `−0.063 rad/s`。行走初态下，相同前进命令的平均前向速度为 `0.227 m/s`，松杆后两秒的前向绝对速度均值为 `0.031 m/s`。

## 结论与阶段判定

这组用例复现了预期的现象。完整参考下的速度误差小于参考速度回放，固定摇杆在近静止时未带出有效步态，行走初态下仍有一定跟随和减速能力。因此，同一个 checkpoint 已能用于起步失败的可复现诊断，可以进入 F1，检验独立速度奖励和独立命令采样能否改善近静止起步、转向及松杆跟随。

结果限于一个片段、一个 checkpoint 和一个种子。旧策略的训练投影与本次 P0 使用的纯航向投影有差别，A 到 B 的性能差异同时可能受投影和参考信息量影响。仿真日志还记录了 28 次求解器线搜索迭代上限警告。这些证据适合筛查和建立回归用例。F1 前后应复用相同初态、命令和速度评分，并报告完整参考的回放结果。
