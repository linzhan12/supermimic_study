# F2.3 第一斜步提前加载前脚方向

合成第一步时保持两个初始足位、支撑脚锚点和最终落脚位置。骨盆在摆脚前开始沿机身前向移动，摆脚结束时平滑回到原终点。用 $s(u)=6u^5-15u^4+10u^3$，归一化时间 $t\in[0,1]$。增加的骨盆偏移为

$$
\delta p(t) = a \left[s(\operatorname{clip}(t/0.39))-s(\operatorname{clip}((t-0.23)/0.77))\right]e_x,
$$

其中 $e_x$ 为初始航向的前轴，$a$ 是实验幅度。两脚位姿仍由阻尼反解投影到原约束。原 motion actor 的目标只包含未来关节位置、关节速度和相对根朝向，骨盆平移是通过投影改变腿部姿态进入跟踪器的。

| 骨盆提前量（m） | 左斜走前向 / 横向（m/s） | 右斜走前向 / 横向（m/s） | 左斜走前 0.60 s 前向（m/s） |
| --- | ---: | ---: | ---: |
| 0.00 | −0.021 / +0.080 | +0.112 / −0.089 | −0.045 |
| 0.04 | −0.015 / +0.078 | +0.108 / −0.092 | −0.036 |
| 0.08 | −0.008 / +0.081 | +0.152 / −0.089 | −0.026 |
| 0.12 | +0.009 / +0.089 | +0.081 / −0.062 | −0.011 |

左斜走前向随提前量增加，0.12 m 时仅整段前向转正，第一步仍微微后退。右斜走第一步使用库中已有的方向参考，前一段的落脚状态不同也改变了右斜走结果。0.12 m 比 0.08 m 的右斜走慢。目标为两侧前向 0.25 m/s、横向幅度 0.20 m/s。本实验结论限于同一冻结策略与初态，仍未达到 F2。

从 `supermimic/` 运行 [预演排序斜步](2026-11-24-f2-sonic-ranked-launch.md) 的 0.60 s 实验，另加 `--contact-launch-forward-lead 0.04`、`0.08` 或 `0.12`，对应 `outputs/f2-sonic-launch-forward-{04,08,12}`。
