# F2.4 变向接缝的支撑投影和预演选择

在实测换向接缝后最多 0.16 s 内，对测速低于 0.25 m/s 的支撑脚做阻尼反解。原姿态的足位与实测锚点按曲线过渡，支撑预定结束或接缝到期时消去修正。对足朝向同样插值。无法满足投影约束时用原窗。用于排序时，每个符合原接缝条件的入点保留未投影和投影两种形状，使用同一初始状态、原权重及接触适配进行预演。执行用最终选中的参考。

| 设置 | 主初态左 / 右斜走侧向（m/s） | 留出左 / 右斜走侧向（m/s） | 主 / 留出右斜走偏航（rad/s） | 主 / 留出末次松杆速度（m/s） |
| --- | ---: | ---: | ---: | ---: |
| 实测接缝，无投影，方向适配 | +0.054 / −0.086 | +0.054 / −0.076 | −0.285 / −0.277 | 0.008 / 0.011 |
| 有投影即执行 | +0.047 / −0.020 | +0.062 / −0.081 | −0.743 / −0.282 | 0.015 / 0.008 |
| 预测选择原窗或投影窗 | +0.062 / −0.083 | +0.062 / −0.080 | −0.282 / −0.278 | 0.013 / 0.012 |

两个初态都选择了投影后的左起步，主场景右侧约 0.20 s 使用投影候选。按预演比较避免了全部强制投影在主初态的误转退化。两个斜走符号一致，实际幅度仍低于 0.20 m/s。右斜走偏航仍偏离零指令。添加 MOSAIC 的强制投影对照仍未选到外部片段。

另外按计划净前向、侧向、偏航方向加单侧亏损处罚，目标轴至少达到 45% 的指令幅度，斜走惩罚超过 0.14 rad/s 的偏航。这是候选目标项，原验收阈值未改。权重 4 或 9 都改变了预测分数，但计划选择和实测动作保持一致。主初态右斜走最初三次重检只剩一个候选，留出右斜走后六次也只剩一个。加强评分无法弥补接缝后的动作覆盖。

复现沿用 [0.06 rad 只做转向适配](2026-11-25-f2-sonic-steering-only-adapter.md) 的主、留出组，分别添加 `--project-contact-seam True` 和 `--project-contact-seam True --rank-contact-seam True`，输出 `outputs/f2-sonic-{contact-seam,ranked-contact-seam}-{main,holdout}`。有方向处罚组沿用 [基础方向适配预演](2026-11-25-f2-sonic-command-scoped-tracking.md)，加 `--direction-cost-weight 4`，留出还试 9，路径为 `outputs/f2-sonic-signed-direction-*`。**F2 未通过。**
