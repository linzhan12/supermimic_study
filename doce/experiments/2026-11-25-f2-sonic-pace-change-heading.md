# F2.4 低摆臂快步换中速的航向保持

新快档 q5242-b 的问题集中在快档切回中档。开放原时序续接作为第一对照。同一周期还在顺序执行且没有形成接缝时，单帧缺少运动学接触标签不拦截继续播放。该改动减少了因空标签被动换片，旧低摆臂库却出现 4 项直走或换速失败，且 q5242-b 中速切换末段仍有 −0.314 rad/s 偏航。不能把缺失接触标签视为唯一原因。

第二对照把有界航向引导用于直走，保持整个前进段或延至实际有换速指令才激活。换速限定同一次连续前进中的速度目标变化至少 0.07 m/s。进入该模式时使用当下实测航向。关节目标与骨盆俯仰、横滚的参考形状保持一致。松杆或收到转向时结束此保持。

| q5242-b 设置 | 换中档末半秒实测前向 / 侧向 / 偏航 | 三档稳态与换速筛查失败数 |
| --- | ---: | ---: |
| 原跟踪 | 0.386 / +0.101 / −0.324 | 1 |
| 接触标签缺失时继续原周期 | 0.269 / +0.088 / −0.314 | 3 |
| 全程前进保持，权重 0.58 | 0.345 / +0.078 / −0.112 | 3 |
| 仅换速后保持，权重 0.58 | 0.342 / +0.061 / −0.070 | 0 |
| 仅换速后保持，权重 0.85 | 0.339 / +0.057 / +0.015 | 0 |

速度单位为 m/s、m/s、rad/s。全程保持改变了左右完整跨步次数。仅换速后保持的两组保留三个稳态的原逐帧结果，并让新的低摆臂快步通过原直走和换速子集。转向及斜走单列联合验证，**当前 F2 未通过**。
