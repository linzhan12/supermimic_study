# F2.3 从双脚实测支撑合成第一斜步

站立或收步时，若传感器确认双脚低速接触且骨盆近静止，构造一个按指令决定摆动脚的过渡。保持支撑脚锚点，先换重，再以五次曲线移动另一只脚，脚间路径最高 5.5 cm。骨盆向新落脚位置平移一半的计划步长，腿关节用双脚位置和姿态的阻尼反解约束。另测令骨盆在起步中短时朝指令方向倾斜。全部使用相同冻结 motion actor。

| 设置 | 左斜走前向 / 横向（m/s） | 右斜走前向 / 横向（m/s） |
| --- | ---: | ---: |
| 航向 0.58，原参考 | +0.063 / −0.060 | +0.294 / +0.010 |
| 0.48 s，合成步后按实测恢复重启 | −0.053 / +0.064 | −0.083 / −0.069 |
| 0.60 s，合成步后按实测恢复重启 | −0.038 / +0.076 | −0.114 / +0.017 |
| 0.76 s，合成步后按实测恢复重启 | −0.041 / +0.076 | +0.012 / +0.010 |
| 0.48 s，加 0.06 rad 前侧倾斜 | −0.048 / +0.067 | −0.071 / −0.067 |
| 0.48 s，加 0.12 rad 前侧倾斜 | −0.048 / +0.084 | +0.109 / +0.054 |
| 0.48 s，加 0.18 rad 前侧倾斜 | −0.038 / +0.085 | +0.056 / +0.094 |

0.48 s 组恢复两侧横向符号，前行方向错误。提高骨盆倾斜后右斜走再次反号。最早组只固定一次合成步，落脚后仍保持起步状态，右斜走基本不动；后续改为结束后按实测速度回到站立或走步，表中为改进后的实现。0.48 s 组最后松杆末半秒约为 `[−0.019, +0.012, −0.019]`，第一项和第二项 m/s，第三项 rad/s。

完整评测使用无合成步的航向 0.58 和扩充库，保存于 `outputs/f2-sonic-bridges-full`。F1 两路完整参考逐字节一致，29 条旧数值条件仍失败。扩大候选还使慢、中档跌出原门槛，中档发生转向候选插入。原单周期候选独立复跑仍通过 `check_gait`，保存于 `outputs/f2-sonic-regression-single-pace`。需要先确保直走候选与方向候选选择互不牵制，再考虑足位和身体姿态的跟踪适配。

## 复现

沿用 [实测静止方向重启](2026-11-24-f2-sonic-directional-restart.md) 的运行，增加 `--heading-strength 0.58 --contact-launch-duration 0.48`，保存到 `outputs/f2-sonic-contact-release-48`。时长另试 0.60、0.76 s。倾斜对照再加 `--contact-launch-lean 0.06`、`0.12` 或 `0.18`，0.48 s 保持固定。完整回归关闭合成步、保留航向引导，去掉 `--planned-only` 与 `--cases`，开启 `--steady-forward True --extra-forward-speeds '(0.22,0.50)' --multispeed-profile True`，然后用 `check_f2_gait.py` 与 `outputs/f2-sonic-current-f1` 比较。
