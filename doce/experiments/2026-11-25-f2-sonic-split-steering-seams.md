# F2.4 踩稳支撑脚时分离转向接缝与上身插值

将此前针对启动的上下身插值延伸到变向接缝。实测和候选支撑脚一致、腿角 RMS 小于 0.18 rad 时适当放宽上身角差。腿和根仍用 0.16 s 接缝，上身延至 0.48 s。方向变化时最短提交时间仍由腿部接缝决定，避免为等上身而冻结一个方向太久。

| 组别 | 左斜走前向 / 横向（m/s） | 右斜走前向 / 横向 / 偏航 | 末次松杆速度（m/s） |
| --- | ---: | ---: | ---: |
| 主初态，原实测接缝 | +0.152 / +0.056 | +0.264 / −0.081 / −0.280 | 0.012 |
| 主初态，分开上身 | +0.022 / +0.003 | +0.324 / −0.078 / −0.884 | 0.027 |
| 留出初态，原实测接缝 | +0.065 / −0.021 | +0.343 / −0.022 / −0.882 | 0.025 |
| 留出初态，分开上身 | +0.019 / +0.004 | +0.322 / −0.083 / −0.911 | 0.026 |
| 留出初态，分开上身并加镜像候选 | −0.026 / +0.060 | +0.128 / −0.052 / −0.015 | 0.722 |

右斜走的偏航轴单位为 rad/s，松杆取末半秒平面速度。拆接缝扩大了可接入候选，但主初态左斜走几乎停滞，镜像组后续停步失效。保留作为回放消融，暂不开启。

同一新联合库采用两种短起步设置时，首个 1.5 s 前向均速从完整低摆臂核心的 0.055 分别提高到 0.201 和 0.284 m/s。普通短起步全筛查 22 项失败，0.48 s 上身分段配合 0.54 s 搜索组 20 项失败。后者转向偏航 +0.354 / −0.369 rad/s，直走中档一侧没有计入完整摆动，换速仍需修复。现有起步与后续周期的物理接缝尚不能同时满足。239 项单元测试通过。**F2 未通过。**

实测接缝沿用 [斜走航向组](2026-11-25-f2-sonic-command-scoped-tracking.md)，再加 `--steering-split-seam True --planned-only True --cases "('stand_start','walk_start')"`，保存到 `outputs/f2-sonic-steering-split-{main,holdout,holdout-mirror}`。镜像组用 [已筛镜像库](2026-11-25-f2-sonic-mirrored-direction-coverage.md)。短起步对照从原 `outputs/f2-sonic-bank-neutral-axial` 副本移除 `start-a.npz` 和 `start-b.npz`，加入隔离方向库的五条 `start-short-*.npz`，其余同直走核心配置。分段组加 `--start-upper-blend 0.48 --start-search-time 0.54`，输出 `outputs/f2-sonic-quick-axial-{plain,split}`。
