# F2.4 按实测初始航向约束斜走，保留独立直走配置

## 斜走的航向

收到横向指令、偏航指令接近零时，以进入该段的实测根航向为锚点。左右斜走连续换向时仍维持该锚点，直到横向操纵结束。对未来参考的根朝向沿用有界引导，只补偏航，保持所有关节目标和参考的俯仰横滚。实际执行与世界模型候选用同一个锚点。采集带锚点的预演日志，核对预测第一步与实际执行的动作一致。

| 组别 | 左斜走侧向（m/s） | 左 / 右斜走偏航（rad/s） | 末次松杆末半秒速度（m/s） |
| --- | ---: | ---: | ---: |
| 主初态，冻结跟踪，无锚点 | −0.047 | +0.012 / +0.016 | 0.391 |
| 主初态，冻结跟踪，有锚点 | −0.047 | +0.012 / −0.013 | 0.091 |
| 主初态，适配预演，无锚点 | +0.059 | +0.278 / −0.380 | 0.013 |
| 主初态，适配预演，有锚点 | +0.056 | +0.151 / −0.280 | 0.012 |
| 留出初态，适配预演，无锚点 | −0.022 | −0.032 / −1.038 | 0.027 |
| 留出初态，适配预演，有锚点 | −0.021 | −0.034 / −0.882 | 0.025 |

航向引导改善了部分误转，留出初态的左斜走继续反号，右斜走仍大幅转向。固定关节参考的侧移质量不足。各组按 [在线消融](2026-11-25-f2-sonic-adapter-online-ablation.md) 运行，启用 `--diagonal-heading-lock True --planned-only True --cases "('stand_start','walk_start')"`。输出 `outputs/f2-sonic-diag-lock-{main,holdout}-{frozen,adapt}`，另有 `outputs/f2-sonic-diag-lock-audit` 以步距 8 的诊断。

## 保留直走配置

显式按上一条非松杆指令的轴向判定是否使用接触适配。直走及直走后的松杆沿用冻结跟踪，带横向或偏航的指令及其后松杆使用训练修正。将已通过数值子集的完整低摆臂库作为直走核心，另接方向起步、斜走与转向片段。在方向库权重对照中，命令损失为 0 或 3，世界模型跟踪排序均开启。

两组均保住了原三档实测 `0.238 / 0.364 / 0.465 m/s` 及直走换速全部旧条件，F1 两条完整参考轨迹逐字节相同。初始 1.5 s 前向均速只有 0.055 m/s，左右转偏航 +0.063 / +0.429 rad/s，两组完整筛查仍均有 16 项失败。初始 1.5 s 也是同一前向指令，必须用可跟踪的快速起步参考提升这个结果，并重新核对连续周期。237 项测试通过。**F2 未通过。**

从 `supermimic/` 建立 `outputs/f2-sonic-bank-neutral-axial`。复制 `outputs/f2-sonic-bank-low-arm-55` 的完整库与 `outputs/f2-sonic-bank-isolated-axial` 中 `diagonal-*`、`turn-*`、`start-left-*`、`start-right-*`、`start-turn-*`。沿用完整在线适配预演，改为新库、`--candidate-entries 1 --adapter-steering-only True`，去掉 `--start-upper-blend` 和 `--start-search-time`。该对照暂不开启航向锚点。命令权重为 0 和 3，输出 `outputs/f2-sonic-neutral-axial-rank{0,3}`。
