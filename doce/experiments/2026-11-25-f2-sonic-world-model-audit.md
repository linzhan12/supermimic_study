# F2.4 同一实测支撑状态下的世界模型短预测

使用 [方向实测接缝](2026-11-24-f2-sonic-measured-steering-seam.md) 的模型和参考库。每 4 个控制步从真实 MuJoCo 状态、实际动作历史和接触出发，计算两个预测。第一个重放实际执行的动作，仅比较学习动力学。第二个由同一个 motion actor 在预测状态上闭环输出动作。只对物理执行与预演保持相同计划、相同指令的时域统计闭环误差。两侧的速度都由同一时域的实际或预测根位移与朝向变化计算，避免混用末瞬速度。另保存实际状态、动作与支撑供后续适配。

| 物理起点 | 预测长度 | 实际动作重放样本 / 闭环样本 | 实际动作重放误差 x / y / 偏航 | 闭环误差 x / y / 偏航 |
| --- | ---: | ---: | ---: | ---: |
| 主序列 walk1_subject1 第 0 帧 | 0.02 s | 132 / 132 | 0.003 / 0.003 / 0.026 | 0.003 / 0.003 / 0.026 |
| 主序列 | 0.10 s | 131 / 117 | 0.004 / 0.004 / 0.048 | 0.004 / 0.004 / 0.023 |
| 主序列 | 0.40 s | 127 / 73 | 0.010 / 0.011 / 0.061 | 0.011 / 0.011 / 0.013 |
| 留出 walk1_subject2 第 50 帧 | 0.40 s | 127 / 71 | 0.012 / 0.010 / 0.052 | 0.012 / 0.007 / 0.010 |

前两列速度误差单位为 m/s，偏航为 rad/s。主序列 0.40 s 的 40 条发生触地状态变化的闭环样本，横向误差 0.013 m/s，对照 33 条接触状态不变样本的 0.008 m/s。主序列左斜走的 0.40 s 实际动作重放，平均横向速度由 MuJoCo 的 −0.042 m/s 预测为 −0.047 m/s，方向同为负。留出初态左斜走同口径的实测为 +0.066 m/s，预测为 +0.079 m/s，仍远低于 +0.20 m/s。预演能够预测这两段的物理运动方向。留出右斜走在 0.40 s 内重规划过，缺少计划不变的闭环样本。以上数据衡量已执行计划的预测质量，其他候选的实际可跟踪性需要额外对照。

主序列与走中起始的完整参考轨迹和旧 F1 逐字节一致。开启诊断后，两路规划轨迹同对应无诊断版逐字节一致。233 项测试通过。保持世界模型冻结，后续在同一被选参考上尝试有限跟踪修正。**诊断不改变 F2 判定。**

## 复现

从 `supermimic/` 使用 [实测方向接缝](2026-11-24-f2-sonic-measured-steering-seam.md) 的命令，额外指定 `--prediction-audit-stride 4`，分别保存在 `outputs/f2-sonic-wm-audit-main` 和 `outputs/f2-sonic-wm-audit-holdout`。留出组额外改为 `--motion-file ../data/lafan1_official/walk1_subject2.npz --stand-frame 50 --walk-frame 231`。每个用例的 `*_prediction.jsonl` 含同起点实测速度、动作重放与闭环预测，`contact_changed` 来自真实脚接触数据。同名 `.pt` 为供本机后续适配使用的张量。
