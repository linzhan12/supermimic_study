# F2.3 用实际骨盆航向引导转向参考

冻结同一 motion actor。只在明确偏航指令活跃时，把参考预测帧的世界航向朝实际骨盆航向加指令积分的方向拉近。前视时间加 0.12 s，角差先限制在 ±0.24 rad 再乘权重。关节参考及骨盆倾斜保持原轨迹。世界模型选择和物理控制使用同样的目标处理。此对照只修改姿态中的偏航通道。

| 航向引导权重 | 左转偏航均值 / MAE（rad/s） | 右转偏航均值 / MAE（rad/s） |
| ---: | --- | --- |
| 0 | +0.108 / 0.350 | −0.348 / 0.376 |
| 0.40 | +0.087 / 0.370 | −0.330 / 0.468 |
| 0.58 | +0.161 / 0.312 | −0.349 / 0.338 |
| 0.70 | +0.239 / 0.271 | −0.567 / 0.390 |
| 0.85 | +0.269 / 0.244 | −0.550 / 0.352 |

左右指令为 +0.40 与 −0.40 rad/s。0.58 组两侧均跨过旧绝对偏航门槛（幅度至少 0.15 rad/s），瞬时误差仍高于相对 F1 容差。更强引导使左转均值提升，但右转超调。各组起步相速度不变。现阶段只验证单场景，不能判断其它初态的效果。F2 仍未通过。

## 复现

使用 [实测静止方向重启](2026-11-24-f2-sonic-directional-restart.md) 的 0.54 s 搜索、三入点、指令损失 3、0.48 s 上身接缝和 `--restart-from-rest True` 命令。分别加 `--heading-strength 0.40`、`0.58`、`0.70`、`0.85`，使用 `outputs/f2-sonic-heading-{40,58,70,85}`。零权重对照为 `outputs/f2-sonic-directional-interrupt`。
